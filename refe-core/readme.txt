Contenuti, campi, blocchi e impostazioni del sito Refe.

== Description ==

Il plugin contiene tutto ciò che non è aspetto: case studies, testimonianze, persone, campi ACF, blocchi, impostazioni del sito, colori e caratteri globali, collegamenti ai dati aziendali e controllo dell'editor. L'aspetto sta nel tema Refe.

Il codice sorgente dei blocchi è nella cartella `src`; la cartella `build` si ottiene con @wordpress/scripts.
